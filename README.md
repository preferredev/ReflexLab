# ReflexLab

An open-source browser FPS aim trainer. Original branding, original scenarios, no proprietary assets.

## Stack

Vite · React · TypeScript · React Three Fiber · Three.js · Zustand · Tailwind CSS · LocalStorage

## Scenarios

| Scenario | Focus |
| --- | --- |
| Grid Rush | Fast target clearing on a grid |
| Micro Control | Tiny targets, micro-adjustments |
| Strafe Track | Tracking a strafing mover |
| Flick Rush | Wide-angle flicks |
| Precision | Accuracy under heavy miss penalty |

## Development

```bash
npm install
npm run dev
```
